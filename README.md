# BCS601-4MW23CS100 – Factorial Generator

## Introduction
Factorial Generator is a simple frontend web application developed using HTML, CSS, and JavaScript.  
The application allows the user to enter a number and generates the factorial value of that number.

This project is created as part of the BCS601 Project Based Learning on Cloud Platform.
